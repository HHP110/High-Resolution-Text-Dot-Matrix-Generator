# 高分辨率文字点阵生成器

[演示预览][demo-preview.png](https://pic1.imgdb.cn/item/68f390103203f7be007beb87.png)

基于网页的高分辨率LED风格文字点阵生成工具，提供丰富的自定义选项。

## 功能特性 

- **多字体支持**：宋体、微软雅黑、Arial、Times New Roman
- **高分辨率**：支持32×32至128×128点阵
- **实时预览**：参数调整即时可见
- **深度定制**：
- 自定义LED颜色
- 可调节点大小比例
- 灵活设置显示尺寸
- 字符间距控制
- **一键导出**：生成PNG格式图片

## 快速开始

1.克隆本仓库。
2.直接打开`index.html`文件或在本地服务器运行。

### 配置参数

生成器接受以下配置参数：

| 参数         | 类型    | 默认值       | 描述                |
|--------------|---------|--------------|---------------------|
| size         | number  | 200          | 画布尺寸(像素)      |
| pointScale   | float   | 0.5          | 点大小比例(0.1-0.8) |
| spacing      | number  | 20           | 字符间距(像素)      |
| ledColor     | string  | '#ffff00'    | LED颜色(十六进制)    |
| bgColor      | string  | 'rgb(50,50,50)' | 背景颜色         |
